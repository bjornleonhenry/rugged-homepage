# Rugged Development Homepage

A modern, responsive homepage for Rugged Development, showcasing services, portfolio, and contact information with smooth animations and professional design.

## Features

- 🏠 Professional homepage layout
- 🎨 Modern animations with Framer Motion
- 📱 Fully responsive design
- 🌙 Dark/light theme support
- ⚡ Fast loading with Next.js optimization
- 🎯 Clean, professional aesthetic

## Tech Stack

- **Next.js** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first styling
- **DaisyUI** - Component library for Tailwind
- **Framer Motion** - Animation library
- **NextAuth.js** - Authentication (if needed)
- **Prisma** - Database ORM (if needed)

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- pnpm package manager

### Installation

1. Install dependencies:
```bash
pnpm install
```

2. Start the development server:
```bash
pnpm run dev
```

3. Open your browser and navigate to `http://localhost:3000`

## Building for Production

```bash
pnpm run build
```

## Deployment

The application can be deployed to Vercel, Netlify, or any other hosting platform that supports Next.js applications.

## Customization

The homepage is fully customizable with:
- Service sections
- Portfolio showcase
- Contact information

- Content management
